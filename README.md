# Market Alert System

AI-based Market Monitoring System

Features:

* Nifty 50 Monitoring
* Nifty 100 Monitoring
* Nifty 500 Monitoring
* Midcap Monitoring
* Smallcap Monitoring
* PE Ratio Monitoring
* PB Ratio Monitoring
* VIX Monitoring
* 50 DMA Monitoring
* 200 DMA Monitoring
* Telegram Alerts
* Daily Market Score

Notifications are automatically sent to Telegram using GitHub Actions.
